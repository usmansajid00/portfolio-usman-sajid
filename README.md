# Portfolio - Usman Sajid

A world-class, professional portfolio website built with Next.js 15, TypeScript, Tailwind CSS, and Framer Motion.

## 🚀 Features

- ✨ Modern, responsive design with dark theme and emerald green accent
- 🎨 Smooth animations and micro-interactions using Framer Motion
- ⚡ Optimized performance (Lighthouse 95+ target)
- ♿ WCAG 2.1 AA accessibility compliant
- 📱 Mobile-first, responsive design
- 🔍 SEO optimized with meta tags and structured data
- 📧 Contact form with EmailJS integration (configurable)

## 🛠️ Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Forms**: React Hook Form + Zod (optional)
- **Email**: EmailJS (configurable)

## 📦 Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

## 🎨 Customization

All content is managed through `data/portfolio.json`. Update this file to customize:

- Personal information
- Experience and education
- Skills and technologies
- Projects and testimonials
- Services and contact information

## 🌐 Deployment

Deploy easily to Vercel:

```bash
# Install Vercel CLI
npm i -g vercel

# Deploy
vercel
```
